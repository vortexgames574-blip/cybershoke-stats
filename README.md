# Статистика матчей Cybershoke

## Установка
1. Откройте терминал в папке проекта.
2. Выполните: `npm install`
3. Выполните: `npx playwright install chromium`

## Как использовать
1. Вставьте ссылки на матчи в `data/matches.txt` (по одной на строку). Первые 4 матча уже добавлены.
2. Выполните команду: `npm run update`
3. Откройте `docs/index.html` двойным кликом или запустите `npx serve docs` и перейдите по ссылке.

## Публикация
Загрузите проект на GitHub и включите GitHub Pages в настройках репозитория (папка `/docs`).
